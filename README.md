# 로컬로 (Localo)

로컬로는 반값여행 참여 지역의 신청 상태와 여행 장소를 지도에서 확인하고, 담은 장소로 예상 경비와 환급액을 계산하는 웹앱입니다. AI 어드벤처 2026에서 4인 팀이 개발하고 있습니다.

## MVP 범위

경남 거창군과 함양군을 시범 지역으로 시작하고, 참여 지역으로 확대합니다.

- **지역 지도** · 신청접수중, 준비중, 마감 상태와 상태별 필터를 제공합니다. 지역을 선택하면 시·군 경계와 식당·숙박·카페·관광지를 볼 수 있습니다.
- **장소 카드** · 확인한 가격대, 접근성, 지도·예약 링크를 제공하고 원하는 장소를 지역별 장바구니에 담습니다.
- **경비 계산** · 식당·카페·관광지는 단가 × 수량, 숙박은 1박 객실가 × 박 수 × 객실 수로 계산합니다. 지역별 인정 경비에 지원 비율과 한도를 적용해 예상 환급액과 본인 부담액을 표시합니다. 장바구니는 로그인 없이 기기에 저장합니다.
- **신청 안내** · 신청 기간과 지원 조건에 출처, 확인일, 공식 공고 링크를 표시합니다. 지원 규칙이 확인되지 않으면 환급액을 ‘확인 필요’로 표시합니다.

## 기술 스택과 데이터

| 영역 | 계획 |
| --- | --- |
| 웹앱 | HTML, CSS, JavaScript 기반 PWA. Next.js 이전은 추후 검토 |
| 지도 | 통계청 행정구역 경계를 SVG로 변환. 인트로 변형에 flubber 사용 |
| 데이터베이스 · 배포 | Supabase(PostgreSQL), Vercel |
| 지역 상태 수집 | Python, Playwright, GitHub Actions로 하루 1회 확인. 누락은 팀이 검수 |
| 장소 데이터 | 한국관광공사 TourAPI 4.0, 카카오 로컬 API, 팀이 조사한 가격대 |
| 지원 규칙 | 팀원이 지자체 공식 공고를 확인하고 신청 기간·인정 경비·거주지 제한 기록 |

## 프로토타입과 후속 기능

- **코스 추천** · 숙소에서 출발해 위경도 직선거리로 방문 순서를 계산합니다(최근접 탐색 + 2-opt). LLM은 정해진 순서에 맞춰 시간대를 배치하고 일정을 설명합니다.
- **장소 정보 추출** · 공식 홈페이지, TourAPI 소개 정보, 메뉴판 사진에서 가격대·영업시간·주차 정보를 추출합니다. 출처와 원문 발췌로 확인되는 값만 저장합니다.
- **후속 기능** · 축제 캘린더, 실제 이동 시간을 반영한 코스 추천, 제휴 사실을 표시하는 예약 링크를 검토합니다.

## 팀

| 이름 | 역할 |
| --- | --- |
| 김지원 | 팀장 · 개발 |
| 박세찬 | 개발 · 데이터 |
| 김수민 | 홍보 |
| 강병지 | 디자인 |

개발 일정은 **2026년 11월 10일~30일**이며, 12월 초 발표를 준비합니다.

## 협업 방식 제안

1. 작업 단위로 Issue를 만들고 담당자와 완료 기준을 적습니다.
2. `main`에서 작업 브랜치를 만듭니다. 예를 들어 `feat/region-map`, `fix/refund-limit`, `docs/readme`처럼 이름을 붙입니다.
3. Pull Request에 연결된 Issue, 변경 내용, 확인 방법을 적고 팀원 1명의 리뷰를 받은 뒤 병합합니다. 화면 변경 시 스크린샷을 첨부합니다.

## 로컬 실행

초기 저장소를 준비하는 단계입니다. 앱 코드가 추가되면 실행 명령과 환경 변수 예시를 이곳에 정리합니다. API 키는 로컬 환경 변수 또는 배포 서비스의 시크릿으로 관리합니다.
